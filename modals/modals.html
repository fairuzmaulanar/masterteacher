Panduan Pemasangan Aplikasi (PWA)

Aplikasi Master Teacher Planner mendukung Progressive Web App (PWA) offline. Karena peramban Chrome memiliki tata letak menu khusus pada berkas lokal, silakan pilih salah satu opsi mudah berikut:

⚡ CARA 1: Langsung Pasang di Chrome Anda Sekarang (Sesuai Menu Gambar Anda)

Pada peramban Chrome versi terbaru saat membuka berkas lokal (file://), tombol pemasangan berada di dalam submenu:

  1. Buka kembali menu Titik Tiga (⋮) di sudut kanan atas Chrome (seperti di gambar Anda).
  2. Arahkan atau klik pada menu: "Cast, save, and share" (atau "Simpan dan bagikan").
  3. Klik pilihan: "Install page as app..." (Pasang halaman sebagai aplikasi) ATAU "Create shortcut..." (Buat pintasan) lalu centang "Open as window".
  4. Klik tombol "Install" / "Create". Ikon Master Teacher Planner akan langsung terpasang di Desktop & Taskbar laptop Anda!
CARA 2: PWA Otomatis 1-Klik (Rekomendasi Service Worker Aktif)
  1. Buka folder proyek aplikasi di File Explorer Windows Anda.
  2. Klik 2x berkas: "Buka-Aplikasi-PWA.bat".
  3. Aplikasi akan berjalan otomatis di http://localhost:8080 dan ikon Install / Monitor resmi di samping bilah URL Chrome akan langsung aktif untuk instalasi 1-klik!
CARA 3: Buat Pintasan Desktop Mandiri (Window App)

Saat membuka di Chrome atau Edge, buka menu Titik Tiga (⋮) > Simpan dan bagikan > pilih "Buat pintasan..." lalu centang "Buka sebagai jendela". Aplikasi akan langsung terpasang di Desktop & Taskbar!

CARA 4: Di iPhone / iPad / Mac (Safari)
  1. Tekan tombol Bagikan / Share (ikon kotak dengan panah ke atas).
  2. Gulir dan pilih "Add to Home Screen" (Tambahkan ke Layar Utama).
  3. Tekan "Add" (Tambah) di sudut kanan atas.
